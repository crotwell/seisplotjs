SeismogramLoader

dist/seismogramloader.mjs

Loads seismograms based on queries to Station and Event web services. Uses the traveltime web service to create times for data query. Default is P-30 sec to S+60 sec.

new SeismogramLoader(stationQuery: any, eventQuery: any, dataselectQuery: any)
Parameters
stationQuery (any) query to find channels
eventQuery (any) query to find events
dataselectQuery (any) optional additional parameters for seismogram query

parseGeoJSON

dist/usgsgeojson.mjs

Parses geojson from USGS feeds. Not all fields are parsed, just basic origin and magnitude along with the id. See https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php

parseGeoJSON(geojson: any): any
Parameters
geojson (any) text from USGS feed
Returns
any: EventParameters, which holds an array of Quake objects

parseFeatureAsQuake

dist/usgsgeojson.mjs

Parses a single GeoJson feature into a Quake.

parseFeatureAsQuake(feature: any): any
Parameters
feature (any) from USGS style geojson
Returns
any: Quake with origin and magnitude
